スキンの作り方 (skins フォルダー)

DeskMeter ヘルプ · 2026-11-08

概要

DeskMeter.exe と同じフォルダーの skins フォルダーに JSON ファイルを置くと、それがスキンになります。ファイル名 (拡張子を除いたもの) がそのままスキン名で、右クリックメニューの「スキン」で、組み込みの 25 種の下に区切り線を挟んで並びます。メニューを開くたびにフォルダーを見直すので、ファイルを足したり消したりしても再起動は要りません。

  • 置き場所: DeskMeter.exe と同じフォルダーの skins\ (無ければ作ってください)
  • 雛形: skins\example-ocean.json (青緑系)。これをコピーして別名にし、色を書き換えるのが近道です。
  • 書かなかった項目は Classic スキンの値になります。背景色と文字色だけ書いた小さなファイルでも動きます。
  • 設定ファイル settings.json には "Skin": "ファイル名" として保存されます。

手順

  1. skins\example-ocean.json をコピーして、たとえば skins\my-skin.json にします (名前は半角英数とハイフンが無難です)。
  2. メモ帳などで開き、色を書き換えて保存します (文字コードは UTF-8)。
  3. ウィジェットを右クリック →「スキン」→「my-skin」を選ぶと切り替わります。
  4. 選んだまま JSON を直したときは、もう一度メニューから同じスキンを選び直すと読み直します。

色の書き方

  • 色は "#RRGGBB" の文字列です (例: "#4FD1C5")。"#AARRGGBB" で透明度も付けられます。
  • DateTile (日付タイルの背景) だけは "#上の色,#下の色" と 2 色をカンマで並べると上下のグラデーションになります。他の項目も同じ書き方でグラデーションにできます。
  • 色の書き間違いは、その項目だけ Classic の値で代用し、理由を deskmeter.log に残します。
  • JSON 自体が壊れている (カンマ忘れ、引用符の欠け など) ときは、そのスキンは Classic として表示され、deskmeter.log に理由が残ります。

項目一覧

全て省略可能です。「使われる場所」は主なものです。

項目型使われる場所 / 意味
FontFamily文字列フォント。カンマ区切りで候補を並べると、先頭から入っているものが使われる (例 "Bahnschrift, Yu Gothic UI, Meiryo UI")
CornerRadius数値ウィンドウの角丸の半径 (0 で四角)。0〜40
Background色ウィンドウの背景色。不透明度はメニューの「背景の不透明度」で別に決まる
BorderColor色ウィンドウの外枠の色。書かなければ枠なし
BorderWidth数値外枠の太さ (既定 1)。0.5〜6
Scanlinestrue / falseCRT 風の走査線を重ねる
TileOverride色これを書くと、全パネルの見出しアイコンの背景がこの 1 色になる (Tiles より優先)
Title色パネルの見出し、Used/Free/Total の見出し行、カレンダーの月と日付、リングゲージの数値など、白系の文字
Text1色CPU 名・クロック、GPU 名と GPU 使用率のバー、Ping、ネットワークの Up、コミット済みメモリ、湿度 など (Classic では黄色)
Text2色VRAM のバー、時計の時刻、Int IP、Down、ドライブの名前と容量、使用中メモリ、降水確率 など (Classic では水色)
Accent1色GPU 温度のラベル、上り・読み取りの ▲、使用可能メモリ、グラフの 1 本目の線、配置編集の挿入位置の目印 など (Classic では緑)
Accent2色Memory Clock、消費電力、Uptime、日の出・日の入、ページプール など (Classic ではオレンジ)
Lime色ネットワークの Peak、ドライブの読み取り速度、時計の日付、天気の気温と地名、予報の降水確率 など (明るい緑)
Warn色温度・メモリが高めのときの警告色
Danger色さらに高いときの危険色、年末カウントダウンの数字
Muted色説明文や単位など控えめな文字 (灰色)
Dim色カレンダーの前後の月の日付など、さらに薄い文字
Magenta色風、ページファイル、リングゲージの 4 本目
Violet色UV 指数、GPU と CPU の Fan、キャッシュ済みメモリ、メモリ構成の「変更済み」
Blue色メモリ構成の「スタンバイ」
Track色バーの背景 (まだ埋まっていない部分)
GraphBg色折れ線グラフの背景
GraphBorder色折れ線グラフの枠線
GraphGrid色折れ線グラフの横の目盛り線
Separator色パネル内の区切り線
CalHead色カレンダーの曜日行の背景
Today色カレンダーの今日の丸
CalSun / CalSat色カレンダーの日曜 (祝日も) / 土曜の文字。省略すると Classic の赤 / 青のまま (Danger や Blue には連動しない)
DateTile色 (2 色可)日付タイルの背景。"#上,#下" でグラデーション
DateTileText色日付タイルの文字
DateTileFont / DateTileWeightフォント名 / "light" "normal" "semibold" "bold"日付タイルの大きな数字の書体と太さ。省略すると FontFamily の細字。組み込みの Classic は "Bahnschrift, Segoe UI" の "bold"
Sun / CloudLight / CloudDark / Rain / Snow色天気アイコンの太陽、雲の明るい面と暗い面、雨、雪
MoonLit / MoonDark色月齢の明るい部分と影の部分
Palette色の配列CPU のコア別バー、プロセス一覧の行の色。先頭から順に使い、足りなければ繰り返す。1 色以上
Tiles色の配列 (6 個)見出しアイコンの背景。順に GPU, CPU, ネットワーク, ドライブ, CPU 上位プロセス, メモリ上位プロセス。6 個ちょうどでないと無視される

"_comment" のように _ で始まる項目は無視されるので、メモに使えます。それ以外の表に無い項目は綴り間違いとみなして、スキンを選んだときに「問題 1 件」のように知らせ、deskmeter.log に項目名を残します (表示はそのまま続きます)。

見た目の拡張項目

色だけでなく、形や飾りも変えられます。組み込みの Kawaii Pink / Synthwave / Matrix などはこれらを使っています。全て省略可能です。

項目型意味
BackgroundGradient"#上の色,#下の色"背景を上下のグラデーションにする (Background より優先)
Card色パネルごとに敷くカードの色。#C8FFFFFF のように先頭2桁で透明度も指定できる
CardBorder色カードの枠線
CardRadius数値カードの角丸 (0〜30)
TileRadius数値見出しアイコンの角丸 (0〜18。18 で丸)
BarStyle"flat" / "pill" / "segment"バーの形: 角丸の四角 / 丸い棒 / ブロック状
GraphAreatrue / falseグラフの折れ線の下を薄く塗る
Decor"sakura" / "hearts" / "stars" / "bubbles" / "dots" / "grid" / "rain" / "lines" / "squares"背景の飾り: 桜の花びら / ハート / きらきら / 泡 / 水玉 / 夕焼けの遠近グリッド / 緑の文字の雨 / ノートの罫線 / 設計図の方眼
DecorColor色飾りの色 (透明度は自動で付く)
Sharptrue / falsetrue で角丸を一切使わない (バー・日付タイル・配置編集の枠も直角、リングゲージは円のままで端だけ直角になる)。CornerRadius / TileRadius / CardRadius を 0 にするのと合わせて使う。組み込みの Classic Sharp / Cyberpunk Sharp / Retro Sharp がこの設定
Mascot"cat" / "bunny" / "bear"いちばん空いている列の下に描くキャラクター。空きが 64px 未満なら描かない
MascotBody / MascotAccent / MascotEye色キャラクターの体 / 耳の内側・ほっぺ / 目の色

うまくいかないとき

症状原因対処
メニューの「スキン」にファイルが出ない置き場所が違う、拡張子が .json でない (.json.txt になっている)、組み込みと同じ名前skins フォルダーが DeskMeter.exe の隣にあるか、エクスプローラーで拡張子を表示して確かめる
選んでも Classic のままになるJSON が壊れているdeskmeter.log の末尾の「Skin ファイル名」の行を見て直す。カンマの付け忘れ・余分なカンマ・全角の引用符が多い
一部の色だけ Classic の色になるその項目の色の書き方が違う (# 抜け、桁数違い)deskmeter.log に項目名と書いた値が残るので直す
コア別バーの色が変わらないPalette の中に 1 つでも書き間違いがある配列は 1 つでも失敗すると全体が無視される。ログを見て直す
見出しアイコンの色が変わらないTiles が 6 個でない、または TileOverride が書いてある6 個ちょうどにする。1 色でよければ TileOverride を使う
