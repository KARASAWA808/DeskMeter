CPU 温度・電力・ファンを表示する (HWiNFO 連携)

DeskMeter ヘルプ · 2026-11-07

概要

Windows の標準機能だけでは CPU の温度やパッケージ電力、CPU ファンの回転数は取れません。DeskMeter はこれらを HWiNFO64 (無料のハードウェア監視ソフト) から受け取ります。HWiNFO64 を起動して「Shared Memory Support」をオンにしておくと、CPU パネルの「Clock:」行の下に次のような行が増えます。

Temp 48 °C  45 W  1200 rpm
  • Temp: CPU の温度。80 °C 以上で警告色、90 °C 以上で危険色になります。
  • W: CPU パッケージの消費電力。
  • rpm: CPU ファンの回転数。

HWiNFO64 が起動していないとき、または Shared Memory Support がオフのときは、この行は出ず、CPU パネルは従来どおりの高さで表示されます。DeskMeter は 60 秒ごとに HWiNFO64 を探し直すので、あとから起動しても最大 1 分で表示されます。取れた項目だけを表示するので、ファンだけ無い環境では「Temp 48 °C 45 W」のようになります。

手順1: HWiNFO64 を入れる

  1. https://www.hwinfo.com/download/ から HWiNFO64 の Installer 版 (または Portable 版) を入手してインストールします。無料版で構いません。
  2. 起動時に「Sensors-only」(センサーのみ) を選ぶと、センサー画面だけが開いて軽く動きます。

この PC には C:\Program Files\HWiNFO64\HWiNFO64.EXE として入っています。

手順2: Shared Memory Support をオンにする

  1. HWiNFO64 のメイン画面 (または Sensors 画面の歯車アイコン) で Settings (設定) を開きます。
  2. Main Settings タブの中にある Shared Memory Support にチェックを入れて OK を押します。
  3. Sensors (センサー) 画面を開いておきます。センサー画面が開いている間だけ共有メモリが更新されます。最小化して構いません。
  4. DeskMeter の CPU パネルに、最大 1 分以内に「Temp ...」の行が出れば完了です。

毎回手で起動するのが面倒なら、HWiNFO64 の Settings で Auto Start (Windows 起動時に開始) と Minimize Sensors on Startup / Minimize Sensors instead of closing をオンにしておくと、ログオン時に自動で裏で動きます。

無料版の 12 時間制限について

無料版の HWiNFO64 では、Shared Memory Support は オンにしてから 12 時間で自動的にオフになります (画面に通知が出ます)。切れると DeskMeter 側の行は消えます。もう一度 Settings で Shared Memory Support にチェックを入れ直せば、また 12 時間使えます。HWiNFO64 自体を再起動したときも、設定が残っていればそこから 12 時間です。

制限なしで使い続けるには、有料の HWiNFO64 Pro ライセンスが必要です。DeskMeter の側に設定はありません。

どの値を取っているか

HWiNFO64 のセンサー画面に出ている名前で、次の順に探します。環境によって無い項目は飛ばします。

表示探す場所優先順位
Temp名前に「CPU」を含むセンサーの温度CPU Package → CPU (Tctl/Tdie) → Core Max → CPU Die (average) → それらが無ければ最初の温度
W名前に「CPU」を含むセンサーの電力CPU Package Power → 名前に「Package Power」を含むもの → 最初の電力
rpmすべてのセンサーのファンラベルが「CPU」ちょうど → 「CPU」で始まるもの → 「CPU」を含むもの

HWiNFO64 でラベルを自分で付け替えている場合は、付け替えた後の名前で探します。読み取りは 5 秒ごとです。
